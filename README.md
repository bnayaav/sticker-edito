# מדבקות ComPhone 🏷️

מערכת לעריכה והדפסת מדבקות מהנייד — מצייר במכשיר, מדפיס במחשב, בגודל פיזי מדויק.

## הארכיטקטורה

```
[נייד - PWA]  ──HTTPS──▶  [Cloudflare Worker + KV]  ◀──polling──  [מחשב - דף הדפסה]
   index.html             worker/src/index.js                       print.html
```

- **`index.html`** — עורך מדבקות לנייד (Hebrew RTL, PWA, ניתן להתקנה במסך הבית)
- **`print.html`** — דף שרץ במחשב, מאזין למדבקות חדשות ומדפיס אוטומטית
- **`worker/`** — Cloudflare Worker שמשמש כתור עבודות זמני (KV עם TTL של 10 דקות)

## איך זה עובד

1. במחשב פותחים את `print.html`, מזינים PIN (4–6 ספרות) וכתובת ה-Worker — והוא נשאר בלולאת polling
2. בנייד פותחים את האפליקציה, מזינים את אותו PIN ואת כתובת ה-Worker בהגדרות
3. עורכים מדבקה בנייד (טקסט, גודל ב־מ"מ, לוגו, מסגרת)
4. לוחצים "שלח להדפסה" — המחשב קולט תוך 3 שניות וחלון ההדפסה נפתח אוטומטית
5. ה-`@page size: WmmHmm` מבטיח שהמדפסת מקבלת את הגודל הפיזי המדויק

## פריסה — צעד אחר צעד

### 1. צור KV namespace

```bash
cd worker
npx wrangler kv:namespace create LABELS
```

הדבק את ה-`id` שתקבל לתוך `wrangler.toml` במקום `REPLACE_WITH_YOUR_KV_ID`.

### 2. פרוס את ה-Worker

```bash
npx wrangler deploy
```

תקבל כתובת כמו `https://sticker-print-queue.YOUR-NAME.workers.dev`. שמור אותה.

### 3. פרוס את הפרונט ל-Cloudflare Pages

הקבצים `index.html`, `print.html`, `manifest.json`, `sw.js`, `icon.svg` יושבים בשורש —
דחוף ל-GitHub וחבר ל-Cloudflare Pages, או:

```bash
npx wrangler pages deploy . --project-name=sticker-editor
```

### 4. הגדרה ראשונה

**במחשב:**
1. פתח את `https://YOUR-PAGES.pages.dev/print.html`
2. הזן PIN בן 4 ספרות (למשל `1234`)
3. הזן את כתובת ה-Worker
4. הוסף את הדף לסימניות / Bookmark / קבע כדף בית

**בנייד:**
1. פתח את `https://YOUR-PAGES.pages.dev/`
2. לחץ על שבב ה-PIN למעלה → הגדרות
3. הזן אותו PIN וכתובת ה-Worker
4. (אופציונלי) העלה את הלוגו של ComPhone במקום ברירת המחדל
5. "הוסף למסך הבית" — מקבל אייקון אפליקציה

### 5. בפעם הראשונה שמדפיסים

בחלון ההדפסה של Chrome:
- **Destination** — בחר את המדפסת שלך (תרמית או רגילה)
- **Paper size** — בחר "התאם לעמוד" / "Fit to page" **או** "Default"
- **Margins** — None
- **Scale** — Default / 100%
- שמור הגדרות אם יש כפתור כזה

עבור מדפסת תרמית למדבקות (Brother QL, Zebra, Dymo) — בחר את גודל המדבקה הקרוב ביותר במנהל ההתקן. ה-`@page size` יעבוד טוב.

עבור הדפסה על דף סטיקרים A4 — המדבקה תודפס בפינה ימין-עליון של דף A4 (ניתן לכוונן).

## תכונות בעורך הנייד

- **Presets לגדלים נפוצים** — תווית לקוח (50×30), מלאי (40×20), מוצר (60×40), ועוד
- **גדלים מותאמים** — הזן רוחב/גובה ב־מ"מ
- **טקסט דו-שורתי** — שורה ראשית גדולה + שורה משנית
- **לוגו ComPhone** — ברירת מחדל מובנית, או העלה לוגו משלך (PNG/SVG עד 200KB)
- **מסגרת** — שחורה עדינה סביב המדבקה
- **תצוגה מקדימה חיה** — בקנה מידה מתאים, מציג את הגודל הפיזי
- **טמפלייטים שמורים** — שמור מדבקות שאתה משתמש בהן הרבה, נטענים בלחיצה
- **סנכרון לענן** — הטמפלייטים נשמרים גם ב-KV ונגישים מכל מכשיר עם אותו PIN
- **PWA מלאה** — עובד אופליין (חוץ מהשליחה כמובן), אייקון במסך הבית

## אבטחה

ה-PIN הוא הרשאה היחידה. כל מי שיודע אותו ואת כתובת ה-Worker יכול לשלוח עבודות הדפסה. בחר PIN שלא קל לנחש (לא 1234), והחלף אותו אם משהו דולף. אפשר להוסיף אימות חזק יותר בעתיד (Bearer token, JWT).

## פתרון בעיות

**המדבקה יוצאת בגודל לא נכון** — בחלון ההדפסה ודא Scale=100%, Margins=None. אם זה עדיין לא טוב, בדוק במנהל ההתקן של המדפסת מה הגודל המוגדר.

**המחשב לא קולט עבודות** — בדוק שהפינים זהים בנייד ובמחשב, ושכתובת ה-Worker תקינה. ב-print.html יופיע "שגיאה" עם הודעה ספציפית.

**הלוגו לא מופיע בהדפסה** — הוודא שהלוגו תחת 200KB. אם זה SVG עם פונט חיצוני, ייתכן שלא ייטען בהדפסה — העלה PNG.

**עבודות נעלמות** — TTL בקוד הוא 10 דקות. אם תור עבודות לא הודפס בזמן הזה, הוא ימחק. נשנה אם צריך יותר.

## שדרוגים אפשריים בעתיד

- שילוב ישיר עם NewOrder — שולפים שם לקוח אוטומטית ויוצרים מדבקת תיקון
- ברקודים / QR codes על המדבקות (jsBarcode + qrcode.js)
- הדפסה במצב "batch" — שולחים 10 מדבקות בבת אחת
- צבעים וצורות מורכבות (אם המדפסת תומכת)
- מצב "דף סטיקרים A4" — עורך שמסדר כמה מדבקות על אותו דף
